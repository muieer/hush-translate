## 2.2.2（自 2.2.1 以来）

- 调整启动时的安装引导：从系统或用户的「应用程序」目录以外启动时，提示先拖拽安装再打开，并停止启动常规服务，避免运行中移动应用后出现朗读失败。
- 安装提示仅保留「打开“应用程序”并退出」操作；移除自动移动、重启和跳过安装逻辑。
- 同步更新中英文安装提示和使用说明。

## 2.2.1（自 2.2.0 以来）

- 在结果窗口切换翻译来源时，原 LLM 服务的请求继续在后台执行；切回相同输入、语言和配置的服务时，复用进行中的请求或已完成的结果，减少重复请求。
- 各 LLM 服务独立维护请求。同一服务的新请求替换旧请求，后台请求的状态、结果和错误不覆盖当前显示的服务；删除服务时取消对应请求并清理缓存。
- 同一截图在结果窗口切换服务时可复用请求和结果；重新截图或切换翻译语言后重新处理，截图结果不进入纯文本缓存。
- 优化中英文 README 的项目介绍。

## 2.2.0（自 2.1.3 以来）

- 原文和译文区域新增朗读按钮，使用 macOS 原生语音合成，支持暂停和继续。开始朗读另一段文本时，停止当前朗读。
- 原文按源语言、译文按目标语言选择系统语音；源语言为自动检测时，使用系统语言识别。支持简体中文与繁体中文的语音语言映射。
- 开始新翻译、替换结果或关闭结果窗口时停止朗读；同一结果刷新时保留播放状态。
- 朗读按钮沿用结果页现有样式，提供播放与暂停图标、中英文文案和辅助功能标签。

## 2.1.3（自 2.1.2 以来）

- 修复翻译结果窗口自动显示时可能被其他窗口遮挡的问题：结果暂时显示在普通窗口上方，不抢占当前应用的输入焦点。
- 点击结果窗口、点击其他窗口或切换应用后，结果窗口恢复正常层级；点击其他普通窗口时，结果排在该窗口下方，不再被放到所有普通窗口之后。手动置顶仍然有效。

## 2.1.2（自 2.1.1 以来）

- 各翻译来源分别在内存中缓存最近一次成功的纯文本翻译。划词与剪贴板翻译可复用同一结果，减少重复请求；输入、语言或相关服务配置变化后重新翻译，退出应用后缓存清空。
- 截图翻译不使用或覆盖纯文本缓存；失败、取消或过期的请求不覆盖缓存，删除服务时同步清理对应缓存。
- 更新「关于」窗口的中英文应用简介，使其同时适用于 Apple 翻译与大模型翻译。

## 2.1.1（自 2.1.0 以来）

- 修复设置页切换界面语言后，翻译会话和截图相关内容未同步切换语言的问题。
- 打开设置窗口时不再自动检测权限，避免因检测触发屏幕录制授权弹窗。首次使用截图翻译或划词会话时，仍会在缺少对应权限时提示；也可在设置中主动重新检测。

## 2.1.0（自 2.0.0 以来）

- 新增简体中文与英语界面，可在「设置 → 通用 → 界面语言」切换；默认保留简体中文。界面语言与翻译语言分别设置。
- 新增英文版使用说明、开发说明、版本记录等文档，并将项目文档集中到 `document` 目录。

## 2.0.0（自 1.1.0 以来）

### 使用条件与默认行为

- 最低系统要求升至 macOS 15.0，macOS 14 不再受支持。
- 默认翻译来源改为无需接口和密钥的 Apple 翻译。升级时保留旧版接口配置为「原有服务」，可在设置中切回。

### 翻译来源

- 新增 Apple 翻译，支持源语言自动检测、按需下载系统语言资源，并在不支持的语言组合上显示错误。macOS 26.4 及以上显式选择低延时策略；较早版本使用系统默认策略。
- 支持保存、编辑、删除和切换多组云端或本地 OpenAI 兼容服务。服务配置整组保存；切换来源时保留设置窗口内的未保存草稿，关闭窗口后丢弃。
- 划词、剪贴板和截图翻译统一使用当前来源。Apple 截图翻译使用本地 Vision OCR；选择 LLM 时，截图图片仍会发送到所选服务，模型需要支持图片输入。
- 结果窗口可直接切换翻译来源，并可调整源语言和目标语言，对同一输入重新翻译，不重新划词、不额外消耗会话次数。切换来源或语言会保存相应选择。

### 划词与设置

- 划词后先显示「翻译」确认按钮；只有点击按钮才模拟复制选区并开始翻译。忽略未确认的划词，不改动剪贴板，也不消耗会话次数。
- 调整设置页表单布局和字段占位提示。
