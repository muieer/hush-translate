# HushTranslate 使用说明

[English](USER_GUIDE.en.md)

HushTranslate 是一款常驻 macOS 菜单栏的翻译工具，支持选中文本、截图区域和剪贴板内容翻译。2.0.0 起要求 macOS 15.0 或更高版本；默认使用 macOS 内置的 Apple 翻译，也可选择自行配置的 OpenAI 兼容服务。

在「设置 → 通用 → 界面语言」可选择简体中文或 English。默认显示简体中文，切换后应用界面随即更新；界面语言不会更改翻译的源语言或目标语言。若系统提示词使用内置默认内容，切换界面语言时也会显示对应语言的默认提示词；自定义内容保持原样。

## 安装与首次运行

HushTranslate 免费分发，发布版使用 ad-hoc 签名，未使用 Apple Developer ID 签名，也未经过 Apple 公证（Notarization）。

1. 从 [GitHub Releases](https://github.com/muieer/hush-translate/releases) 下载 `HushTranslate-x.x.x.zip`。
2. 解压 ZIP 文件。
3. 建议将 `HushTranslate.app` 移至 `/Applications`（应用程序）文件夹，也可放在其他位置。
4. 双击应用。macOS Gatekeeper 可能阻止首次打开；此时前往「系统设置 → 隐私与安全性」，找到 HushTranslate 的提示，点击「仍要打开」，并按系统提示确认。
5. 启动后，按系统提示授予所需的「辅助功能」「屏幕录制」等权限。具体用途见下方「系统权限」。
6. 默认使用 Apple 翻译，无需配置接口或密钥。macOS 26.4 及以上显式选择低延时策略，较早版本使用系统默认策略；需要语言资源时按系统提示下载。使用 LLM 时，可在设置中添加服务；API Key 由用户自行获取，费用由自己的服务商账号承担。

## 使用前准备

- 系统要求：macOS 15.0 或更高版本。
- 启动后，HushTranslate 以气泡图标显示在菜单栏，不会打开主窗口。
- 点击菜单栏图标并进入「设置…」，选择翻译来源、语言、快捷键和权限。LLM 服务配置需整组点击「保存」；来源和语言选择即时保存。

## 翻译来源与服务设置

在「设置… → 通用」的「翻译来源」下拉框中选择「Apple 翻译」或已保存的 OpenAI 兼容服务。划词、剪贴板和截图统一使用当前来源。源语言可设为自动检测，目标语言需指定具体语言。

Apple 翻译是默认且不可删除的选项，不需要接口配置。macOS 26.4 及以上显式选择 `lowLatency`，较早系统使用默认策略；缺少语言资源时，结果窗口会激活并显示系统下载提示。自动检测会先在本地识别源语言；无法识别时交由系统翻译会话继续处理，必要时提示选择语言。翻译在本机完成；不支持的语言组合会显示错误，可更换语言或翻译来源。

使用 LLM 时，点击「添加服务」并填写：

- **服务名称**：用于区分配置，例如「火山云」「本地 Ollama」。同一服务也可保存不同模型的多组配置。
- **接口地址（Base URL）**：HTTP 或 HTTPS 基础地址，例如 `http://localhost:1234/v1`，不要包含 `/chat/completions`。
- **API Key**：服务商提供的密钥；本地服务按其要求填写。
- **模型名称**：接口使用的模型名称。

点击「保存」后，新服务会加入列表并成为当前来源。编辑服务同样需要点击「保存」；「取消修改」恢复已保存的值。切换来源会保留各服务的草稿，但不会提交；关闭设置窗口后丢弃未保存修改。删除当前服务后自动切换为 Apple 翻译。

升级后默认选择 Apple 翻译，旧接口迁移为「原有服务」，可从下拉框切回。设置中的修改从下一次请求起生效，不自动重新翻译已有结果，也不影响正在进行的翻译。

## 翻译功能

三项功能都可从菜单栏启动，也可使用全局快捷键：

| 功能 | 默认快捷键 | 操作方式 |
| --- | --- | --- |
| 开启翻译会话 | `⌃⌥⌘D` | 先开启会话，再在其他应用中拖动划词、双击选词或 Shift 点击扩选。点击选区上方的「翻译」按钮后才执行翻译。默认允许 3 次点击翻译，单纯划词不扣减次数；再次按快捷键重置为 3 次，不立即翻译当前选区。 |
| 截图翻译 | `⌘⌥⇧S` | 触发后拖动框选屏幕区域；按 `Esc` 取消。 |
| 剪贴板翻译 | `⌃⌥⌘V` | 先将文本复制到剪贴板，再触发翻译。 |

可在“设置… → 快捷键”中点击录制框，重新设置或清除快捷键。

## 截图翻译模式

选择 Apple 翻译时，截图固定使用本地 Vision 识别文字，再将识别结果交给 Apple 翻译；不会将图片发送到 LLM。识别失败或为空时会显示提示。

选择 OpenAI 兼容服务后，在「设置… → 截图翻译」中可选择：

- **本地 Vision**：先使用 macOS Vision 识别文字。
- **多模态大模型**：直接由模型识别并翻译图片。
- **本地优先**：先使用 Vision；本地识别失败或结果为空时，让模型识别图片。

使用 OpenAI 兼容服务时，截图翻译始终保留图片输入并发送到所配置的服务，所选模型需要支持图片。「本地 Vision」表示 OCR 先在本机执行，但图片仍随请求发送，LLM 翻译也不离线。切换到 Apple 时会保留此前的 LLM OCR 模式，切回 LLM 后恢复。

## 系统权限

- **辅助功能**：选中文本翻译需要此权限，用于模拟 `⌘C`。
- **屏幕录制**：截图翻译需要此权限，用于读取屏幕内容。

可在“设置… → 快捷键 → 权限”点击“去授权”打开对应的系统设置。授权后返回 HushTranslate 点击“重新检测”；辅助功能授权后若仍不能使用，请退出并重新启动应用。

剪贴板翻译不依赖上述两项权限。

## 翻译结果窗口

结果窗口显示原文、译文和耗时。顶部来源名称为「Apple 翻译」或「服务名称 - 模型名称」，取自本次请求使用的配置，并支持：

- 选择并复制窗口中的文字；
- 一键复制原文或译文；
- 在窗口顶部切换翻译来源、源语言或目标语言，重新翻译同一输入并保存选择，不消耗划词会话次数；
- 点击图钉使窗口保持在最前方；
- 点击窗口标题栏的关闭按钮；结果窗口获得焦点后，也可按 `Esc` 关闭。

内容较长时可在窗口内滚动。当前版本不保存翻译历史。

## 高级设置

“设置… → 高级”提供以下选项：

- **请求超时**：设置等待模型响应的最长时间，仅适用于 OpenAI 兼容服务，各组 LLM 共用。
- **自定义系统提示词**：仅适用于 OpenAI 兼容服务，各组 LLM 共用；选择 Apple 时禁用。整段作为 system 消息发送，支持 `{sourceLanguage}`、`{targetLanguage}` 和 `{input}` 三个变量，也可恢复默认内容。
- **检查权限**：重新检测辅助功能与屏幕录制权限。
- **显示数据目录**：在 Finder 中打开 HushTranslate 的应用数据目录。

## 常见问题

- **选中文本没有反应**：确认会话已开启且已授予辅助功能权限，选中文字后点击「翻译」按钮；部分浏览器、Electron 应用或远程桌面可能不响应模拟复制，可先手动复制，再使用剪贴板翻译。
- **截图无法开始**：确认已授予屏幕录制权限；授权后重新触发，必要时重启 HushTranslate。
- **Apple 翻译失败**：根据提示更换语言或手动选择源语言；语言资源下载失败时，检查网络后重试。应用不会自动改用 LLM。
- **LLM 截图识别成功但翻译失败**：确认模型支持图片输入，并检查接口地址、API Key、模型名称和网络连接。
- **接口报错或响应超时**：检查模型服务是否运行、接口是否兼容 `/chat/completions`，以及“高级”中的请求超时设置。
- **找不到应用窗口**：HushTranslate 是菜单栏应用，请在屏幕右上角的气泡图标中操作。

点击菜单栏中的“退出”可完全退出 HushTranslate。
